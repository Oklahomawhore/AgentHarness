# 复合原生工作快照

[English](README.md) | 中文

本参考文档描述无密钥的 `sdk/scope-native-work` 场景。两个原有 Session 保留各自的本地 Task、工具、身份和历史。接收 Session 拥有共享 Task。另一个 Session 通过一次联合授权读取该 Task，并贡献明确选择的文件操作、精确命令结果和完整最终答复。读取许可独立于贡献撤销。

来源执行真实 Write、Read、Edit、成功的 Bash 命令和最终答复，再执行同一命令得到失败结果并给出另一份最终答复。六个样本共用一个 capture、grant、累计序号和额度。Read 不被采集。当前命令结果替代先前成功结果；两份最终答复保留为独立、有来源的报告。所有者撤销授权后，当前上下文撤下全部六份报告，先前接收历史仍被记录。本场景不要求空闲来源立即结算其远端采集记录。

四个真实接收请求覆盖初始本地 Task、两个工作阶段和撤销，每次受管上下文不超过 8,000 字节。fixture 将精确请求与内存及落盘 Session 重建比对。原始 `.dsh/native-work-audit.json` 包含原任务归属、来源请求和事件、发送前持久化样本、命令结果、完整 Task 报告及独立读取的文件内容。私有输入与授权前输出不进入共享上下文。

随产品提供的 SDK profile 在单机上使用受控 provider 回复和经过认证的进程内传输。本场景的测试文件系统 provider 展示 `/workspace` 路径，同时保留真实目标身份与 I/O。它不衡量付费模型、物理多设备交付或空闲时自动响应。[测试文档](../../../docs/testing.zh.md)定义快照与 Python 运行器。
