# 原生文件操作完成文本快照

[English](README.md) | 中文

本文说明 `sdk/scope-completed-file`。正式 SDK profile 启动接收方，其拥有的 Loader fixture 启动独立来源 Host。认证使用进程内传输，不是独立物理设备测试。只有模型回复使用脚本；文件操作、本地授权、Task 准入、共享上下文交付和 Session 持久化均使用生产实现。

来源文件在授权前已经存在。明确的 `fileContent: completed-native-file` 同意允许分享未修改的文件正文以及编辑参数。来源执行一次真实 Read 和三次真实 Edit，没有 Write。接收方第一次请求包含第一次操作的完整结果，第二次请求包含第三次 Edit 的结果，前两条报告标为已被替代。停止精确来源采集后，三条报告均在第三次请求前撤回。未操作的对照文件始终不进入共享上下文。

每次请求均在归一化前，将完整消息与冻结内存和已刷盘 Session 文件所独立重建的消息比较。断言独立核对原始 Edit 参数、版本三许可、完整结果摘要、来源身份、替代和撤回。Python 重复三个回合，将归一化 Session 与 TypeScript 记录比较。两个来源文件均与 `source-workspace.expected/` 核对。

来源执行六次受控模型请求，接收方执行三次，且不调用 recall 或文件工具。完整共享消息保持在 8,000 字节以内。本场景证明已授权操作结果的交付，不证明接收方理解、任意外部文件变化、送达时磁盘现状或纯 Edit 历史容量。来源为自身工作读取文件的权限不自动授权分享完整文件。[测试文档](../../../docs/testing.zh.md)说明运行器及其构建产物要求。
