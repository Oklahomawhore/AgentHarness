# 前台命令结果快照

[English](README.md) | 中文

本参考页说明 `sdk/scope-command-outcomes`。正式 SDK profile 启动接收者；归属本场景的 Loader fixture 启动独立来源 Host，并挂载生产文件系统、Bash 执行器、subprocess 提供方和原生采集服务。认证使用进程内传输，因此不验证实体设备或网络可达性。只有模型响应由脚本控制。

来源仅授权分享根索引零下精确命令 `bash verify.sh` 的结果。两次真实 Write 修改私有脚本，两次真实前台 Bash 执行该脚本。第一次退出零并输出 `COMMAND_PASS`；第二次退出一，输出 `COMMAND_FAILED` 及独立 stderr。脚本内容没有分享许可。第一次接收请求包含成功尝试，第二次包含后续失败并替代早先成功，第三次发生在精确来源采集撤回后。最终脚本与 `source-workspace.expected/verify.sh` 独立核对。

每次请求在归一化前，都与冻结 Session 事件及已刷盘 Session 文件分别重建的完整消息比较。断言将 owner 准入的命令字段与真实类型化执行器完成结果、独立预期输出核对，不解析渲染后的退出标记。Python 重复相同三轮，检查持久化的命令身份、授权、结果、来源覆盖与撤回，并将归一化 Session 与 TypeScript 记录比较。

来源产生六次受控模型请求；接收者产生三次，不使用 recall 或命令工具。每个完整共享帧保持在 8,000 字节以内。本场景证明两次明确授权执行结果的交付，不证明当前代码通过验证、模型理解了证据、任意命令都可安全分享，或执行器保留结果以外的输出被采集。超时、中止和截断由来源与后端所属测试覆盖，不在本场景中重复。[测试规范](../../../docs/testing.zh.md)负责运行器及构建产物要求。
