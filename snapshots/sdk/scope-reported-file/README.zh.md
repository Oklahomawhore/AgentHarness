# 报告文件快照

[English](README.md) | 中文

本参考说明无需密钥的 `sdk/scope-reported-file` 场景。发布的 `dsh --profile sdk` 启动接收者；场景拥有的覆盖配置创建独立来源 Host，使用生产原生工具和持久存储。两个 Host 使用经过认证的进程内传输，不代表独立应用进程或物理设备。

一个明确授权的本地采集对实现文件和配套文件执行两次真实 Write 与四次真实 Edit。接收者首先记录实现的原始 Write 和配套文件的重建结果，随后记录两个完整的 `reported-files` 结果。它们分别依赖四项和两项操作，保留确切授权、文件身份、有序依赖摘要，以及报告不能核实当前文件的警示。停止确切采集后，两个派生文件均被移除，六项来源全部标为撤回。原始文件和 Session 历史保留。

每次实际接收请求在规范化前，都与从冻结内存以及刷盘后的 Session 头和事件重建的完整消息比较。独立展开还原两个重建记录共用的完整 grant 值。Python 重复三个回合，将规范化 Session 与 TypeScript 记录比较，并核对原始请求字节、内容、依赖摘要和撤回。两个来源文件均与 `source-workspace.expected/` 比较。独立 writer 期望保留每份已提交世代。

来源执行八次受控请求，接收者执行三次。没有付费模型调用；脚本化回答不能确立模型理解。本场景验证持久化表示与出处，不证明长历史容量、没有授权 Write 的编辑或私有文件披露。完整共享包裹文本保持在 8,000 字节以内。[测试文档](../../../docs/testing.zh.md)负责快照、Python runner 及构建产物要求。
