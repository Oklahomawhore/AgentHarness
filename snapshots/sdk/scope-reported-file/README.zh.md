# 已报告文件快照

[English](README.md) | 中文

本文说明无需密钥的 `sdk/scope-reported-file` 场景。正式 `dsh --profile sdk` 启动接收方，其拥有的配置层创建独立的来源 Host，使用生产原生工具和持久化存储。两个 Host 使用进程内认证传输，不是两个独立应用进程或物理设备。

一次明确授权的本地采集执行真实 Write，随后执行三次真实 Edit。接收方先记录未改写的原始 Write，再记录完整的 `reported-files` 结果，包括精确本地授权、文件标识、四条所选来源引用、有序依赖摘要，以及报告不能证明当前文件的说明。停止这一精确采集后，派生内容被移除，四条来源记录均标为已撤回。原文件和 Session 历史保留。

每次接收方实际请求都在归一化前检查，包括包含派生文件的请求。其完整消息分别与冻结的内存事件和已刷盘的 header、事件所独立重建的 Session 消息比较。Python 驱动相同的三个接收方回合，比较完整归一化 Session，并独立检查原始请求字节、内容、依赖摘要和撤回证据。来源的真实文件与 `source-workspace.expected/state.ts` 比较。

来源执行六次受控请求，接收方执行三次。没有付费模型调用；脚本回复不证明模型理解。本小场景检查持久化表示和来源，不证明四十次 Edit 的容量、没有授权 Write 的编辑或私有文件防泄露。接收方完整共享消息保持在 8,000 字节以内。[测试文档](../../../docs/testing.zh.md)说明快照、Python 运行器及其构建产物要求。
