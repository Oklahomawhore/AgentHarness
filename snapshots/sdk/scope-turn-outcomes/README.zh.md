# 完整最终答复贡献快照

[English](README.md) | 中文

本参考说明 `sdk/scope-turn-outcomes`。已发布 SDK profile 启动接收者；私有 Loader 组合启动独立所有者与来源。来源没有 Session 工作目录、文件系统服务或注册的文件工具。只有模型响应经过脚本控制。进程内认证传输不能确立跨物理设备运行。

原来源 Session 在同意前完成私有答复，随后获得显式最终答复分享许可。之后两个普通 user 通道回合分别产出完整答复，其中一次响应包含私有推理。接收者的三个回合依次观察第一条答复、两条独立答复，以及精确贡献撤销。不调用逐次发布或 recall 工具。原始私有提示、推理及同意前答复留在来源本机；最终答复仍可能在披露许可范围内引用输入内容。

每次样本发送前，夹具读取来源 Session 文件并核对完整持久证据。每份接收请求都在归一化前从冻结事件和实际 Session 文件分别重建。Python 重复三个回合，独立核对来源正文摘要、原采集归属、准确线上事件、保留的历史与当前撤回。每份完整共享消息保持在 8,000 字节以内。

该场景验证获准非代码报告的自动采集与交付，不核实报告为事实、不推定后续答复取代旧答复、不证明模型理解，也不授权自动执行。来源生命周期测试负责失败、追加输入、超大及恢复回合的排除。[测试文档](../../../docs/testing.zh.md)负责快照运行器与构建产物要求。
