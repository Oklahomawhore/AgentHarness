# Recipient context budget snapshot

English | [中文](README.zh.md)

This reference describes the keyless `sdk/scope-recipient-budget` scenario. The shipped SDK profile creates B's Session; a private Host composition creates A's executing owner Session. Both use production tools and durable Session storage. The authenticated transport runs in one process; it does not demonstrate a cross-device connection.

B starts with a local Task, ordinary conversation history, and working tools, without any local capture. A single joint application grants reading and file contribution, with automatic responses disabled. A completes real Writes to three independent files. Its complete projection exceeds B's unchanged 8,000-byte allowance; B's combined request reserves at most 4,000 bytes for local Task context and selects complete remote file groups within the remaining allowance. The fixture compares each selected report's original text and requires explicit budget omissions in the actual model request. It measures remote framing from the actual request text and verifies that the owner's allowance equals 8,000 minus the actual local context and complete framing bytes. B then completes a real Write whose report enters A's next ordinary request without recall or copied factual prompts.

Leaving ends B's remote subscription and contribution while preserving its original Task epoch, Session history, tools, and absent local capture. Managed local and remote context in each actual request is compared with detached reconstruction before normalization; final managed contexts are also reconstructed from flushed disk headers and events. Python drives the same four ordinary turns and compares B's complete normalized Session oracle plus a summary. A's managed-context comparisons apply within each execution; its request counts and byte totals enter the summary, not a separate cross-run Session oracle.

`session.v3.jsonl` supplies the user turns and recorded replies; `replay.override.json` drives seven B model requests. A uses six controlled requests. `workspace.expected/` independently fixes B's resulting file contents. No model call is paid, and the assertions make no model-quality claim. The passive collaboration UI does not yet display per-request admitted bytes or omission counts; this scene checks the durable model-facing evidence directly. [Testing](../../../docs/testing.md) owns the snapshot and Python smoke runners and their built-artifact requirements.
