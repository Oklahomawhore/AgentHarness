# 原生同伴贡献快照

[English](README.md) | 中文

本参考说明 `sdk/scope-native-contribution`。发布的 SDK profile 拥有独立来源 Host、Task owner 和接收 Session。真实文件工具、持久来源记录、owner 准入和上下文注入通过经过认证的进程内传输运行。这不确立物理设备连接能力。

来源明确同意且 owner 批准后，三次真实工具操作产生客户端更正和指南。报告后端在第一次接收请求中重建客户端。随后的替代 Write 和失败 Edit 使第二次请求保留三条完整的原始同伴报告。报告后端可通过观察引用与 grant 引用编码这些报告；独立展开将每份原文和 grant 与 owner 已准入的 publication 比较。Owner 撤权后，第三次请求撤回全部五项来源记录。过程不使用接收者 recall 工具或手动发布。

每次实际接收请求的全部消息都在规范化前，与冻结 Session 事件和已刷盘持久事件的完整重建结果比较。Python 独立展开原始请求表示，将其与同一批已准入报告及规范化 TypeScript Session 比较。已提交的输入和早期 writer 世代保持不变。

来源执行五次真实工具调用和七次受控模型请求；接收者执行三次受控请求。完整共享包裹文本限制为 8,000 字节。这些检查确立披露、精确表示、替代和撤回，不确立真实模型理解或空闲自动协作。[测试文档](../../../docs/testing.zh.md)负责支持的 runner。
