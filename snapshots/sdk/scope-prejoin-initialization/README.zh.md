# 已记录本地工作初始化快照

[English](README.md) | 中文

本文记录无密钥场景 `sdk/scope-prejoin-initialization`。正式 SDK profile 创建来源 Session；两个私有 Host 组合分别提供共享 Task 所有者和第二个执行 Session。传输采用经过身份确认的进程内投递，不代表跨设备连接。

来源在申请共享读取前真实完成 Write、Edit、失败 Edit 和私有目录 Write。显式初始化许可选定当前本地采集与 Task 代际；等待所有者批准时完成的 Write 也纳入选择。第二个 Session 不同意历史分享而正常加入。所有者只接收获准目录与工具，本地根目录序号重新映射到远端许可。独立修改磁盘内容并监控文件系统操作，可区分已有记录与文件扫描。

每个请求均对完整本地上下文与带封装的远端上下文合计执行 12,000 字节上限。冻结的模型请求展示历史投递、精确自身采集省略、第二个 Session 未许可的历史缺席、后续实时更新、撤回和本地工作保留。独立磁盘修改后，后续 Write 前真实执行 Read，以遵守通常的文件观察策略；初始化本身不读取内容。脱离服务的 Session 重建和实际磁盘持久重建均比较未归一化的原请求上下文。Python 驱动同一组合，比较完整当前 Session 预期与独立摘要。截止时刻并发、丢失回复去重和重启恢复由来源包测试覆盖。

`session.v3.jsonl` 提供用户轮次和录制响应，`replay.override.json` 驱动生产工具；`workspace.expected/` 独立固定来源的最终文件内容。本场景不调用付费模型，也不证明模型质量。使用仓库快照与 Python scope smoke 命令选择本场景名称；运行器与构建产物要求由[测试文档](../../../docs/testing.zh.md)说明。
