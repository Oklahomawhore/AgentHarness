# 混合命令与已完成答复的上下文

[English](README.md) | 中文

这个无密钥 SDK 场景将实现 Agent 与独立的审批评审 Agent 连接到同一 Task。命令来源运行八条不同的获准 Bash 命令，再重复其中一条并产生失败结果。答复来源没有文件系统工具，在一条授权前的私有回合之后贡献一条明确获准的最终答复。两个来源保留原 Session；接收者保留原身份、会话头与工具。

三个接收请求检查初始混合报告、变更的命令结果和答复撤回。完整受管上下文保持在 8,000 字节内。当前命令的省略仍明确记录；密集命令不会挤掉独立的完整答复。夹具核对已准入 publication、原 grant、实际子进程结果、发送前的来源持久化、精确请求重建和保留的 Session 历史。Python 独立检查同一证据，并将归一化 Session 与 TypeScript 记录比较。

这个场景使用已发布的 SDK profile、受控模型答复和进程内认证传输。它不确立真实模型理解、自动执行、跨物理设备网络或发布就绪。Bash 夹具控制自身退出结果；其报告不认证应用代码。来源容量竞争另由采集器 Loader 测试通过明确的持久化屏障验证。
