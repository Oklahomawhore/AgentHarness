# Agent Note: Scope 产物判分器

Status: implemented

[English](2026-10-03-scope-artifact-oracle.md) | 中文
## 问题

传输成功和上下文进入请求，不能证明接收 Agent 正确改变了工作。模型即使确认更新，仍可能发出旧请求字段或生成放行所有实现的测试。如果判分器向接收者共享答案字节，结果也会失效。

## 决策

[Scope 评测 owner](../../../../scripts/scope-evaluation/README.zh.md)依据受控正确实现和明确错误变体，检查实际前端请求与 QA 行为。案例对象和源码字符串必须来自它的受控注册表。离线 runner 在执行前记录源码与案例字节，拒绝替换结果，并把所有输出标为零次模型试验的判分器自检。

单独的文件工作台提供精确文件权限，不提供任意 shell。它拒绝路径穿越和符号链接，但不宣称操作系统隔离。[受控执行决策](2026-10-03-scope-native-evaluation.zh.md)负责说明 Docker 隔离与报告来源限制；判分器仍拒绝未经审核的模型产物。

## 考虑过的替代方案

**确认消息或输出字符串匹配。** 这些结果不能展示正确代码或有区分能力的测试。评测目标是实际请求行为与错误变体检查。

**把受控响应当成协作试验。** 确定性案例证明检查器识别已知行为；它们不能证明模型拿到上下文后会做什么。模型试验保持独立注册、分母和用量证据。

**把目录分离或 Node 权限当成安全保证。** 独立工作目录不限制读取。Node 权限模型不是恶意代码沙箱。离线检查器仅接受自己经过审核的源码；Node 权限不能替代它的执行策略。

## 后果

独立的[数据产物试验](2026-10-04-scope-data-artifact-study.zh.md) 通过固定解释器接受未知 JSON，不替代本决策对可执行源码的限制。

仓库获得可复现的产物判分能力，不据此宣称产品收益。五个合成案例范围有限，不覆盖任意语义决策。离线命令不能证明真实 provider 行为、公平基线对比或模型成本。[运行时校准决策](2026-10-03-scope-native-evaluation.zh.md)负责说明产物识别之外的执行证据。
