# Agent Note: 普通 Agent 数据产物

Status: implemented

[English](2026-10-04-scope-data-artifact-study.md) | 中文

## 问题

受控 JavaScript oracle 无法在不信任生成程序汇报进程的前提下，对未知模型源码评分。[受控原生校准](2026-10-03-scope-native-evaluation.zh.md) 保留为独立运行时检查；使用注册正确输出无法衡量普通接收 Agent 是否在自主工作中采用共享更新。

## 决策

[JSON 工作试验](../../../../scripts/scope-evaluation/data-study/README.zh.md) 接受有上限的策略和 QA 数据，由父进程持有的固定解释器计算实际请求轨迹。候选产物不包含可执行表达式或成绩字段。父进程在 Session 结束后封存最终字节，独立检查策略行为与 QA 区分能力。参考输入和错误策略不进入模型可访问文件或工具。

固定源 Agent 使用生产原生文件工具与贡献采集。普通接收方使用生产 HTTP provider 和精确文件权限。显式 N/E/R 注册保留相同公开项目、目标和预算。源更新完成后才启动接收方，本试验不证明既有 Session 内的持续采用。运行故障、数据无效、行为失败和本机 HTTP 校准分别记录。

有限调用预留先于模型委派。用量缺失停止后续委派；执行目录已存在时禁止自动重试并重置预算。静态预检核对记录字节，不加载凭据。这些机制使已授权执行可复核，而不把尚未执行的注册当作模型证据。

## 考虑的替代方案

**移除 JavaScript 注册限制。** 容器隔离不能认证候选程序的汇报来源。既有[受控 oracle 决策](2026-10-03-scope-artifact-oracle.zh.md) 仍适用于可执行程序。

**按确认语句或精确 JSON 字符串评分。** 确认语句不能证明行为，等价 JSON 也可能拥有不同字节。固定解释器评估请求轨迹，同时保留原始提交字节供审计。

**先建设通用代码判分器。** 有限数据任务允许自主未知输出和独立评分，代价是不能覆盖广泛编程任务，也不能证明普遍协作质量。

## 后果

本试验提供可执行的普通 Agent 入口和可信数据解释器，不代表已证明产品收益。同机工具不宣称操作系统隔离，单波次合成结果不能证明跨设备可靠性或持续撤回行为。产物、注册与原生校准检查由[评测参考](../../../../scripts/scope-evaluation/data-study/README.zh.md#evidence-and-limits) 持有。
