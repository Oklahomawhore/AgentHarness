# Agent Note: 在线贡献审批保留来源同意范围

Status: implemented

[English](2026-10-03-online-contribution-approval.md) | 中文

## 问题

传递贡献申请再带回批准邀请，需要来源用户协调两次交换。浏览器不能独自安全完成审批：页面可能关闭、回复可能丢失，也可能仍显示用户已经取消的采集。减少这类协调仍须保留独立的来源文件许可与所有者发布授权。

## 决策

[所有者服务](../../../../packages/collaboration/scope-access/README.zh.md) 为自己拥有的 Root Task 和明确来源模式签发申请入口。持有入口不授予读取或发布权限。经过认证的来源以一个持久采集身份、精确来源许可，以及明确的到期时间、样本数和字节限额认领入口。所有者在来源限额内批准该选择；其他设备、采集、来源或变更后的同意范围不能复用它。

所有者在同一个串行操作中先持久保存完整审批决定，再打开 [Task 授权](2026-10-03-independent-scope-contributions.zh.md)。Task 事件仍是唯一发布授权依据。回复丢失或 Task 提交中断后，状态查询和重试恢复同一个计划授权。申请记录负责协调审批，不能代替 Task 事件授权样本。

取消和拒绝先持久保存终结意图，再结束关联授权。已保留的计划授权可以在延迟的打开操作之前结束，产生阻止重新打开的持久 Task 终结事件。确认须等待精确的终结授权记录。没有计划授权或既有授权的入口可以直接关闭，无须构造授权；这关闭的是该入口，不禁止所有者另行批准独立的手工申请。入口过期阻止新申请与批准，但已经批准的选择仍可查询状态和取消。

[来源适配器](../../../../packages/collaboration/claude-scope/README.zh.md) 在发送申请前持久保存精确本地采集策略及有界的自动启用同意。Host 拥有的后台任务在页面关闭后仍取回审批结果。每个会话只拥有一个后台任务；对等请求在全局本地修改队列之外运行。每次回复采用时都检查当前采集身份和取消信号，重新核对读取许可关系并在线验证授权。任何回复都不能扩大本地选择或同意限额。

来源退出和 SessionEnd 先停止本地采集，再等待远端确认。即使没有邀请，待确认的申请取消仍会保留，不能套用手工路径的空选择清理。重启使用原本地设备身份恢复已保留意图。释放服务会中止并等待后台任务结束。所有者不可用时保留可见的待确认状态；显式提供的新地址可以更新同一入口的连接，但不能变更采集或恢复已取消的活动。

[客户端控件](../../../../packages/client/ui-emergence-center/README.zh.md) 保持来源同意与所有者审批显式可见。提交后的状态通知使本地观察失效；管理操作及结果不确定后，界面重新读取权威状态。[手工控件](2026-10-03-independent-contribution-controls.zh.md) 仍可用于单独审批和地址恢复。读取订阅与有限次数的自动模型执行继续各自要求授权。

## 已考虑的替代方案

**由来源页面轮询。** 关闭或重载页面会暂停审批取回，并丢失与待确认本地取消的关联。持久且由 Host 拥有的后台任务让用户已有的同意继续生效，无须再次粘贴。

**将申请记录视为写授权。** 申请持久化与 Task 准入分别提交。将申请作为授权可能在审批提交失败后发布，或在 Task 尚未终结授权前确认撤回。

**没有邀请时清除取消。** 即使回复丢失，审批也可能已经提交。保留入口与采集身份后，所有者才能恢复并终结该授权。

**在适配器共享队列内轮询对等方。** 所有者无响应会拖延无关会话的 hook 和本地停止。该队列只容纳本地快照读取与结果采用。

## 影响

在线路径用一次入口交换代替申请与批准邀请的往返交换。用户仍须选择会话、本地采集策略及贡献限额，所有者仍须批准。交付要求已公布的对等地址可达且 Host 正在运行；本决策不提供公共发现、中继或 NAT 穿透。支持的[来源模式](2026-10-03-independent-tool-observations.zh.md)决定哪些已授权 Write/Edit 工作会贡献内容；入口不授权任意工具输出。

定向 Host 测试覆盖丢回复、重启、同意限额、审批与取消顺序、延迟验证、无关会话继续工作及后台任务释放。浏览器验收由[在线贡献场景](../../../../apps/web/tests/online-contribution-scope.e2e.ts) 拥有。这些检查以受控输入验证设置、授权和交付行为，不证明真实模型任务质量或物理跨机器易用性。
