# Agent Note: 可替换的接收者 Task 上下文后端

Status: implemented

[English](2026-10-02-recipient-task-context-backend.md) | 中文

## 问题

原生 Task 消费者将上下文选择与完整 JSON 渲染器耦合。替换选择逻辑需要修改 Session 准入，而且每个参与者都收到相同的发布内容。异步提供者还引入绑定竞态：在某次 Task 绑定期间计算的结果，不能进入之后的绑定期间，即使两次复用同一个绑定 id。

[Scope 上下文提案](../../proposed/architecture/2026-10-02-scope-context-backends.zh.md) 要求先提供可替换的计算能力，再实现自动采集和投递。现有 [Task 模型](2026-08-28-task-context-atoms-and-session-bindings.zh.md) 仍是显式发布、谱系和独立 Session 绑定的权威说明。

## 决策

[Task 上下文包](../../../../packages/collaboration/development-task-context/README.zh.md) 拥有 `/backend` 服务定义、`/text` 服务提供者和请求时消费者。提供者计算文本及来源覆盖范围，不修改 Task 状态或 Session 历史。Loader 挂载提供者和消费者；抽象服务定义不是第二个需要挂载的提供者。这些角色在共同演进期间放在同一个包中。

文本提供者保留原始 Task 目标、范围和完整发布内容。 通用文件报告遵循[完整 Write 检查点和整段预算](../feature/2026-10-04-tool-report-checkpoints.zh.md)。它排除接收者自己发表的内容，并在完整文本字节限制内选择其他发布内容。来源记录区分已包含内容、自有内容排除和预算省略。这是确定性筛选，不是语义相关性判断或事实协调。提供者不能声称已采用省略的材料。

每次请求捕获当前 Task 修订和最近一条持久 `task-bound` 事件的节点与序号。该事件标识绑定区间。异步计算结束后，消费者重新检查区间和提供者生命周期。绑定变化会在同一个 pre-step 内重新选择，保留待准入的用户消息批次。新增的只追加发布内容不会使仍可使用的结果失效；后续请求会处理较新的修订。

提供者身份及处理修订、文本预算、Task 修订和绑定区间决定是否复用。提供者或预算变化会在实时请求上产生新投影。未变化的投影和回放使用日志中的原文；历史事件不会经由新后端重新解释。

首次投影加入 pre-step 消息批次，让 Agent 循环先建立受保护的系统消息首节点，再准入上下文。已有投影的替换使用持久 surface 操作。[断开撤销](../bug-fix/2026-10-02-task-context-disconnect-withdrawal.zh.md) 保留历史，同时从后续请求中移除本插件的旧上下文。

提交投影的 Session 事件是采用状态的权威记录。Task 确认是准入之后发出的派生回执。失败会被报告，并从已有投影重试，不重复计算，也不中断模型请求。Task 执行器在串行操作内部校验可选的预期绑定 epoch，防止旧回执确认之后的绑定区间。原生投影始终提供该 epoch。回执标识已投递的视图修订，不证明模型使用了每项事实。

## 考虑过的替代方案

**将渲染保留在消费者内。** 这使语义处理无法与生命周期分开，并让每个新后端重复实现请求来源记录和绑定检查。

**绑定变化时拒绝该 step。** 循环已经领取输入消息，拒绝可能丢弃用户请求；重新计算能保留请求，同时排除已放弃的结果。

**追加首次投影之前先确认。** 后续准入可能失败或取消，产生没有 Session 记录的回执。准入后确认保留了唯一的本地采用权威。

**一开始就加入 latent 载荷分支，并为每个角色拆包。** 本次增量没有兼容的 latent 接收端，三个角色也只有一个当前消费者。文本实现建立实际行为，不提前发布不支持的表示分支。

## 影响

后端可以替换，无需修改 Task 成员关系、网络传输或 Session 投递。文本筛选不需要额外模型调用。投影变化可能使模型请求后缀缓存失效；复用避免重复选择和重复上下文事件。

[原生贡献采集](../feature/2026-10-04-native-scope-contributions.zh.md)和[语义处理](2026-10-03-audited-semantic-context.zh.md)使用这套后端分离机制。仅通过后端和回放测试，不足以证明语义保真、任务改进或产品成熟。
