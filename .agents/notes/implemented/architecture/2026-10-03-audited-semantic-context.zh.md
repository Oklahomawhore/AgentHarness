# Agent Note: 带审计的按接收者生成的语义上下文

Status: implemented

[English](2026-10-03-audited-semantic-context.md) | 中文

## 问题

独立 agent 会围绕不同职责产生报告。将每条获授权的 Write/Edit 正文复制给所有接收者会消耗上下文，却不能说明哪些更新与其任务相关。语言模型摘要可以选择并压缩报告，但也会引入模型费用、证据省略，以及仅回放原始报告无法复现的生成结果。

## 决策

[语义后端](../../../../packages/collaboration/development-task-context/README.zh.md#semantic-backend)通过既有 LLM 服务，按 Task 目标和接收者标签汇总捕获的获授权报告。Task 与 scope 消费者继续负责授权、接收者 binding 和采纳检查。标签指导相关性判断，不授予访问权限。模型为每条普通来源明确作出判断，并为每个包含的来源引用确切摘录。缺失或无关引用会使输出被拒绝。引用校验确立来源对应关系，不证明语义准确。

确定性选择在推理前排除已撤回的来源区间和已被替代的类型化观察。当前结构化 OpenAPI 证据和终结通知保持为必需记录。模型不会用自己的解释替换这些记录。继承证据仍是单独注明出处的冻结历史。完整投影文本必须符合配置的字节预算；无效或超出预算的摘要不会被旧结果替代。

隔离的 JSONL 持久化服务拥有一个身份稳定的辅助审计 Session。预备但不发布该 Session 可防止它出现在活动存储枚举中，单独的持久化目录也可防止普通 Session 查询发现它。审计在调用模型前记录并刷写确切的生效请求和累计调用预留；向消费者返回前，记录并刷写有界原始输出、提供方报告的用量和已验证的确切投影。既有消费者将交付投影记录在接收方 Session 中。

已完成的相同请求复用耐久结果。恢复时从记录的原始输出和捕获来源重建每条已完成投影。并发的相同读取共享一次计算；最后一个读取者离开时取消该计算。释放会等候计算和审计写入完成，再释放写入器。有已记录结果的失败尝试可在剩余预留限额内重试；中断且没有结果的请求保留为结果未知、已消耗的预留，不会被隐式再次发送。配置 revision 不会重置同一审计身份下的限额。

## 考虑过的替代方案

**通过确定性字段选择复制报告。** 这对结构化 OpenAPI 证据仍然有效，但不能面向不同接收者压缩任意代码和文档报告。

**让模型重写全部 scope 状态。** 撤回、已知来源覆盖范围和未解决的结构化冲突不能依赖相关性判断。后端单独保留这些记录。

**只将生成文本保存在内存或接收方 Session。** 重启后会丢失确切辅助请求、原始结果及费用依据。提供方拥有的审计支持确切复用，消费者则保留自己的交付记录。

**在普通持久化目录中使用未发布的 Session。** 查询服务独立于活动 Session 的发布情况扫描持久化日志。因此，必须隔离持久化，才能使辅助请求不进入普通对话查询。

**重试每个缺失结果的请求。** 进程可能在调用之后、提交结果之前停止。自动重试可能重复付费调用；该预留保持已消耗，结果明确为未知。

## 影响

接收者可获得简短且带来源的更新，无需选择逐条报告。摘要推理增加延迟和 token，相关性判断可能省略有用信息。确切摘录不证明摘要保留了否定、不确定性或含义。调用次数、字节、并发和时间限额约束执行；提供方未报告用量时，不能据此声称确切的金额上限。

受控提供方测试覆盖来源核对、持久化隔离、撤权、取消、重启和模型请求投影。这些检查确立链路和失败行为，不证明真实模型任务收益、摘要保真、跨机器性能、embedding 通信或产品成熟度。

[语义试验](../../../../scripts/scope-evaluation/semantic-pilot/README.zh.md)在调用前冻结六个接收者与 revision 组合，并独占创建执行阶段，避免重复运行静默重置已消耗的预留。生产 HTTP 校准将传输证据与语义审阅分开。用量未知时停止后续调用；估算费用阈值不能替代提供方的计费约束。结构化引用检查不能确立命题保真，因此仍需人工审阅。
