# Agent Note: 独立工具观察共享有界工作事件

Status: implemented

[English](2026-10-03-independent-tool-observations.md) | 中文

## 问题

协作者会修改代码和文档文件，这些文件无法全部注册为 OpenAPI 工件。要求手工发布或为每次更新选择单个文件，会阻止普通工作自动贡献内容。扩大采集范围必须保留本地同意、独立 owner 授权、精确重试身份和撤回，且不能把工具报告表述为已验证的当前状态。

## 决策

[既有独立贡献生命周期](2026-10-03-independent-scope-contributions.zh.md)接受第二种来源许可：具名的 Write/Edit 工具集合。来源用户一次选择本地根目录和允许的工具。Owner 通过[单入口申请](2026-10-03-online-contribution-approval.zh.md)或显式邀请批准相同来源和有界同意范围。入口、申请、邀请、样本及耐久解析器都约束来源模式。接收仍须独立授权；来源不获得 Task 副本或 Room 成员资格。

[Claude 适配器](../../../../packages/collaboration/claude-scope/README.zh.md)只采集匹配且已授权的工具租约。结构化报告包含所报告的成功或失败、根目录序号、相对路径、工具字段及明确的整字段省略。Write 携带内容；Edit 携带旧／新文本和规范化的全部替换意图。失败操作省略被尝试的成功正文。完成时重新检查本地许可和已保留输入身份，再持久保存精确样本。该模式不授权任意 Bash 输出、对话记录、目录扫描或额外文件读取。

[Task owner](../../../../packages/collaboration/development-task/README.zh.md)验证来源与工具的关联以及完整请求预算，派生归属和规范正文，并按递增序号保留每个事件。结构化元数据不包含绝对根目录和 Session 标识；用户撰写的工具正文仍是用户数据，其自身可能包含敏感字符串。认证标识报告者，不证明执行或真实性。这些事件使用 `peerToolObservation`，与可替换的 OpenAPI 证据分离。文本后端可以包含多个文件事件；OpenAPI 事实后端将它们记录为不支持的证据，不提取虚构事实。

原有耐久 outbox、精确 payload digest、匹配收据、预留终结容量和待确认撤回适用于两种来源模式。终结排除该 grant 的所有当前报告，不删除历史，也不召回已经交付的字节。未标记的 OpenAPI 来源及其 payload digest 保持既有表示。工具模式记录使用显式标签，严格恢复的记录保留来源关联。这是向前读取受支持的表示，不保证降级。

## 考虑过的替代方案

**为每个文件要求 OpenAPI 选择器。** 代码和正文不具备受支持的 OpenAPI 操作。人为选择器会把工具事件错误表达为完整工件快照，并且仍要求逐文件配置。

**接受调用方撰写的任意发布文本。** 这会绕过来源与工具关联、owner 生成的归属及有界结构化省略。报告可以包含不可信文本，同时保留可执行的采集许可约束。

**只保留每个路径的最后事件。** Edit 描述被报告的转换，失败操作也不会替换文件内容。把事件归并为当前文件会断言 owner 未观察到的状态。

**另建工具贡献权限协议。** 既有贡献身份、同意、恢复和终结规则均适用。来源判别字段扩展该授权，无需引入第二份写权限记录。

## 影响

对不同文件的普通获许可工作可以直接贡献，无需额外选择器或逐次分享操作。报告仍会消耗存储、上下文预算，并可能消耗自动激活次数。本决策不提供面向接收者的语义整合、通用冲突解决，也不证明模型有效利用了这些信息。

定向 [Task 测试](../../../../packages/collaboration/development-task/tests/peer-contribution.spec.ts)覆盖来源／工具不匹配、有界准入、精确重试、耐久出处和终结历史。[Scope 测试](../../../../packages/collaboration/scope-access/tests/tool-contribution.spec.ts)覆盖在线批准、不同文件报告、回复丢失后的 owner 重启、独立接收和撤回。无密钥模型请求验收及浏览器检查由消费者场景负责，不属于真实模型质量或物理跨机器证据。
