# Agent Note：独立贡献的接入与恢复

Status: implemented

[English](2026-10-03-independent-contribution-controls.md) | 中文

## 问题

贡献者需要选择一个本地文件，获得 Task 所有者批准，再启用普通工具操作带来的自动共享，无需调用管理 API。刷新、丢失回复、旧页面与连接地址变化必须保留原授权，不能创建另一份授权或重新启用已停止的采集。

## 决策

[来源适配器](../../../../packages/collaboration/claude-scope/README.zh.md)通过本地认证接口提供采集详情，不依赖 Task 成员身份。读取详情不采样文件，也不联系所有者。在手工路径中，来源端准备不含路径的版本化申请，所有者批准，来源端再确认启用。[客户端控件](../../../../packages/client/ui-emergence-center/README.zh.md)将此过程与读取邀请、有限模型执行许可分别管理。

每次本地修改均指定预期采集代际。适配器在取消此前工作前检查选择，并在修改队列内再次检查。旧页面不能停止或替换后来创建的许可。客户端在组件重新挂载后保留待完成的修改，拒绝被替换选择或连接的迟到观察，并在成功或结果不明后重新读取本地授权。重新读取失败时，修改控件保持不可用，直到刷新成功。

[所有者服务](../../../../packages/collaboration/scope-access/README.zh.md)根据所有者、Task、贡献者与采集区间派生授权身份。Task 队列仍是唯一授权来源。相同批准复用原授权；额度变化、来源变化或授权已终结都不能悄悄创建新许可。所有者使用当前确认的连接地址恢复已存储授权。活跃与终结记录均通过按稳定授权身份排序、受完整字节预算限制的分页提供；这些页面不构成冻结快照。

替换地址不能改变任何授权字段。来源端先保留新路由，再在线验证对端身份与收据，保留原采集与待提交样本。待撤回状态可使用恢复的路由请求终结收据，但不能激活。恢复所有者的已终结记录不会重新开启授权。连接身份、本地文件许可、写入许可与读取许可仍分别管理。

## 已考虑的替代方案

**在浏览器生成授权身份。** 丢失回复或刷新页面可能产生另一份授权。持久 Task 记录和确定性批准身份使重试不依赖浏览器内存。

**把邀请当成实时授权。** 粘贴文本可能已过期、已撤销，或面向另一个采集区间。预览校验其表示；激活仍要求匹配本地选择并在线验证所有者。

**隐藏终结记录或拒绝地址变化。** 贡献者可能已在本地停止，但所有者的终结收据丢失。通过已确认地址恢复原终结授权，可以完成清理而不恢复采集或发布。

## 影响

手工路径要求选择确切的 API 文件，并各转交一次申请与邀请；[在线审批](2026-10-03-online-contribution-approval.zh.md) 在明确同意自动启用后只交换一次入口。后续支持的普通工具工作复用已有自动采样与投递链路。这些控件不提供对端发现、NAT 穿透、通用语义提炼，也不证明模型正确使用了收到的上下文。

浏览器验收使用独立认证的 Web 组合以及受控文件和模型输入。Host 测试覆盖丢失回复、采集替换、不可变批准额度、分页和路由恢复。这些检查证明授权与运行时行为；真实模型任务质量与跨机器易用性需要单独证据。
