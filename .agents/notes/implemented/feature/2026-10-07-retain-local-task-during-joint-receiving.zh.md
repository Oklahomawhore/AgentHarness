# Agent Note: 联合接收保留参与者原有的本地职责

Status: implemented

[English](2026-10-07-retain-local-task-during-joint-receiving.md) | 中文

## Problem

人们带着已有的 Agent、Task、历史和权限围绕共同目标协作。要求 Agent 先退出自己的 Task，才能接收另一所有者的当前事实，会丢掉使协作成为必要的原有职责。分别注入本地和远端上下文，还可能重复调度或超出配置的请求预算。

## Decision

[原生接收者](../../../../packages/collaboration/scope-agent-context/README.zh.md)支持明确组合精确的原本地 Task 分配与一个独立读取订阅。加入保留 Agent、Session、Task 世代、工具权限和独立授权的本地采集。调用方确认本地目标和已观察的接收状态；普通工作不会使同意失效，后来的管理决定会。[联合贡献流程](2026-10-04-native-joint-join.zh.md)将该目标与来源同意一同保留。

一个接收者持有双方来源的请求准入和自动调度。它在配置上限内计算本地上下文，将剩余容量交给远端所有者，并在获准的远端读取后同步验证本地分配和提供方。[接收者容量决策](2026-10-07-recipient-context-budget.zh.md)拥有分配和有界协议语义。两份精确投影共用一份完整 UTF-8 消息预算，包括包裹文本与撤回标记。实际模型请求证据保留两份投影的身份与来源序号。通知或预取投影不能证明采用、完成或执行权。

参与者单独为组合绑定授权本地目标与有限自动额度。原本地自动策略被保留以便退出时恢复，但不授权对新远端 scope 作出响应。外部采用等待原持有的自动轮次结算后，再安装新绑定。从该自动轮次内部发起采用会被拒绝，以免等待自己。真正并发的暂停、退出和重新绑定决定使待采用操作失效。Session 已消耗额度保持单调。待采用的组合计划暂停原策略；采用失败或取消不会隐式恢复它。

退出移除原操作持有的远端订阅，并为保留的分配恢复一个新的本地调度区间。保留的自动策略处于暂停状态，保留目标、上限和已消耗额度；待启动触发及已完成响应的比较基线不会恢复。过期的本地分配不能授权响应，退出也不会清除替代 Task。独立文件采集继续受自身同意约束。后续明确恢复需要当前权限与剩余额度。

组合绑定与双来源证据使用严格的插件负载版本。历史本地单来源与远端单来源记录保持原有解释。这不改变 Session 容器格式，也不重写已提交的 Session 世代。[独立采集目标](2026-10-06-independent-native-capture-destinations.zh.md)继续持有报告权限和终止规则。

## Alternatives considered

**把参与者迁到所有者的 Task。** 这会移除原有人类职责，而不是连接其 Agent，并改变普通工作的权限归属。

**运行两套注入器与调度器。** 各自合法的输入相加后可能超出单次请求预算，同一变化也可能触发重复自动工作。组合准入在一个本地执行决定下保留双方来源。

**将本地自动许可复制到共享 scope。** 用户原先授权的是另一套上下文与目标。保留原策略供暂停恢复，既保存策略，也不扩大其权限。

**本地自动工作活跃时拒绝所有加入。** 外部确认可以等待所持有的工作结算。要求再次批准会使正常加入依赖偶然时序；只有等待自身或同意已被取代时才需要拒绝。

## Consequences

既有工作无需 recall 调用或 Task 迁移，即可接收另一所有者的事实。接收者需要维护两份独立证据，并在准入时重新验证；这不是分布式原子快照。被动接收等待普通请求。自动响应保持可选且有限，重启不会恢复执行许可。

行为验证覆盖陈旧同意、活跃轮次结算、双来源预算与证据、当前事实替换以及暂停恢复本地策略。已交付配置的 SDK 和浏览器场景覆盖既有本地工作从加入到退出的过程。受控模型响应证明这些机制，不证明真实模型质量、双人易用性或公网可达性。
