# Agent Note: 以独立来源同意分享完整答复

Status: implemented

[English](2026-10-14-completed-answer-contributions.md) | 中文

## Problem

研究、评审和产品工作可能不修改文件，也不执行命令。要求这些参与者另行发布上下文消息，会重新引入独立所有 Agent 本想消除的同步工作。反过来，导出任意对话文本又会在缺少准确、可审阅来源许可的情况下披露私有输入和中间推理。

## Decision

[原生贡献消费者](../../../../packages/collaboration/scope-agent-contribution/README.zh.md)提供独立的完整最终答复来源。许可仅在持久批准与原在线运行时激活之后生效。实际未取消的 next-turn inbox 领取确立单条 user 通道来源；最后进入的 step 必须以完整可见助手答复结束，回合必须正常完成。通道标签是运行时来源证明，不代表确有物理人类输入。追加输入与托管自动回合被排除。

只有完整文本块组成报告。推理、原始用户输入与工具记录不直接复制，但答复可能引用私有材料。披露表单在同意前说明这一后果。字节超限会整条省略答复。Session 检查点与不可变 outbox 先于同伴提交；等待存储后重新核对停止、到期、运行时身份及本地绑定。冷恢复会终结原许可，不重放历史答复。

采集器按原租约身份统计排队中的完成结果和已保存样本。持久化保存可能在工作者移除完成结果前通知另一个即将结束的回合；同时统计这两种表示，会在样本或保留上限处丢弃本应获准的答复。若改为在保存前移除完成结果，则存储失败时会丢失可重试的工作。本地与同伴许可保留各自的租约，同一实际回合同时贡献到两处时也不合并。

来源具有独立的第 5 版许可及线上协议，不能解释为文件或命令授权。Task 准入记录包含完整正文摘要、原来源及采集身份的报告。后续答复不能确立前一答复已被更正，因此两者独立保留归属，直到撤回或明确报告省略。仅支持 OpenAPI 的事实后端不能证明答复覆盖完整。[人的职责](../process/2026-10-05-collaboration-follows-human-responsibility.zh.md)仍决定协作成员与本地执行同意。

## Alternatives considered

**要求显式发布工具。** 这会让来源 Agent 每次更新都决定同步内容，并使非代码参与者继续手工维护共享上下文。

**导出所有完成回合。** 自动响应可能把自身产出反馈进另一自动响应，而失败、中断或被追加输入的回合也不能确立所选来源的含义。

**把最新答复当作当前事实。** 两份答复可能描述不同主题或相互矛盾。序号只证明来源顺序，不证明语义替代或所有者核实。

**从加入或文件分享推定许可。** 读取、工具执行、文件报告与最终答复披露授权不同的信息和动作。

## Consequences

该来源在同意后消除逐条答复分享步骤，同时保留独立所有的 Session 和权限。它不核实陈述、不选择协作者、不分派工作，也不授予自主执行。外部适配器须先有可靠的最终答复来源证明才能支持该来源；Claude hook 适配器会拒绝它。

[原生工具来源决策](2026-10-04-native-scope-contributions.zh.md)继续负责实际文件系统执行与恢复。[同伴原文编码决策](../bug-fix/2026-10-14-lossless-peer-report-text.zh.md)继续负责逐字节保留的表示。答复采集不替代这两项决策。Loader 生命周期测试、实际 TypeScript 与 Python SDK 请求以及浏览器同意流程验证该来源；受控模型响应不能证明语义质量或跨物理设备运行。
