# Agent Note: AgentHarness 局域网一句话安装

Status: implemented

[English](2026-08-27-agentharness-lan-one-command-installer.md) | 中文

## 问题

免源码压缩包仍要求普通用户找到正确产物、安装 Node.js、解压文件、保留路径、启动运行时，并把该路径转换成三种 MCP 客户端配置。AgentHarness 没有可以承载这套分发流程的内网下载域名或文件服务器。

## 决策

发行负责人的电脑可以暂存带校验值的发布集合，并通过私有 IPv4 地址下的随机 URL 路径提供只读服务。发布器会为已暂存的目标打印 shell 或 PowerShell 安装命令。每个生成的安装器都固定到一个版本及每个可用目标的 SHA-256；shell 安装器选择调用方的 macOS 或 Linux 架构，PowerShell 安装器接受 Windows x64。

便携产物包含 Node.js 可执行文件及其许可证。安装过程使用内容寻址的版本目录，只有下载、校验值、压缩包路径、清单和运行时检查全部通过后才切换 `current` 符号链接或 Windows junction，并把 Harness 用户数据留在版本目录之外。激活过程使用内置 Node 运行时的原子 rename 语义，确保 macOS 会替换已有 symlink，而不是跟随它。安装后的 `agentharness` 命令负责后台启动、状态、日志、停止和 MCP 指南输出。

## 进程所有权

管理命令会在仅 owner 可访问的状态目录记录派生 PID、准确的 `start.mjs` 路径、版本、端口、URL 和日志路径。只有操作系统报告的该 PID 命令仍包含所记录的入口路径时，停止或升级才会发送信号。就绪条件遵循[启动决策](../bug-fix/2026-10-24-local-descriptor-startup-readiness.zh.md)；进程退出或就绪超时会返回带日志路径的错误。

## 持久节点身份

源码与便携启动器会在加载房间或任务存储前使用同一个身份解析器。它依次选择显式 `DSH_ROOM_NODE_ID`、持久房间日志中唯一且一致的 owner、安装身份，最后才生成新的本地身份。身份文件以仅 owner 可访问的权限原子写入。错误身份和不存在唯一一致 owner 的持久日志会失败关闭；内部一致的旧 `standalone` 日志会在保留备份后迁移。便携压缩包把共享解析器声明为必需资产，避免源码与安装后的启动路径再次静默分叉。

## 分发安全

静态服务器只公开一个随机路径下的普通文件，并拒绝其他方法、目录访问和路径穿越。随机路径只能减少偶然发现，不是认证。发布器与安装器都会说明局域网明文 HTTP 允许局域网攻击者截获或替换内容。该流程仅限受信任局域网，并要求负责人在分发后停止服务；安装后的 Web 运行时仍只监听 loopback。

PowerShell 安装器接受 tar 的 `./` 根目录项和相对成员路径，但在统一分隔符后拒绝绝对路径、驱动器前缀及 `..` 路径分量。生成的正则表达式使用字面点字符类，避免 JavaScript 字符串转义把父目录分量检查变成任意字符匹配。

## 验证

定向测试通过本地 HTTP 服务执行原样 curl 管道，覆盖带空格路径、同版本重放、在已有 `current` symlink 上激活另一个内容寻址版本、首次成功安装后篡改压缩包、拒绝不安全下载源与路径穿越、拒绝未受管且正在响应的端口，以及后台启动、状态、幂等启动和停止。构建产物验收使用内置 Node 执行 Task／上下文 MCP 操作，并验证 Web 重启后的持久化。原生 Windows CI 负责执行生成的压缩包路径检查，以及 PowerShell 安装、重启、MCP 不支持提示和 Cursor 配置保全检查。

## 考虑过的替代方案

**等待永久内网域名。** AgentHarness 目前没有获批主机，这会保留安装缺口并阻塞 alpha 分发。

**把压缩包提交到 Git 或 Gitee。** 大型平台产物不应进入源码历史，而且下载后仍要每位用户自行选择、验证、解压、启动和配置 MCP。

**要求系统 Node.js。** 这样压缩包更小，但默认安装路径仍保留版本敏感的前置条件。内部 alpha 新用户引导更适合较大的自包含产物。

**把随机 HTTP 路径当作安全访问控制。** 它无法阻止网络上的观察或修改。实现会显示该限制，不宣称具有认证能力。

## 影响

内置 Node.js 会增加压缩包大小，但让安装路径不再要求用户预先准备特定版本。每个暂存目标都需要匹配的运行时和原生依赖。shell 路径覆盖 macOS 和 Linux；`install.ps1` 是 Windows x64 路径，该系统仍不支持私有本地 MCP 认证。发行负责人进程停止后局域网发布随即结束，这是临时分发模式的预期行为。
