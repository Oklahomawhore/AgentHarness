# Agent Note：在既有 Agent Session 之间分享原生命令结果

状态：已实现

[English](2026-10-07-native-command-context.md) | 中文

## 问题

职责不同的人在自己的 Agent Session 中运行检查。仅有文件变更不能告诉协作者后续命令已失败。新失败出现后，共享的成功不能继续代表当前结果，打印输出也不能冒充进程退出状态。

## 决策

原生采集可独立选择精确前台命令与工作目录序号。同一许可仍可独立选择文件工具。这只授予结果分享许可，不执行命令，也不扩展来源 Agent 的工具。[原生贡献 README](../../../../packages/collaboration/scope-agent-contribution/README.zh.md) 负责选择、额度、撤回及恢复规则。

Bash consumer 发出实际前台开始与 provider 完成观察。采集器要求原 Session 调度、所选 provider、最终工具结果及持久 Session 检查点均吻合，之后才保留样本。报告包含有界进程事实，不解析展示文本，也不读取输出暂存文件。最终工具失败仅携带不可用证据。[工具 README](../../../../packages/shell/tool-bash/README.zh.md) 负责观察事件。

所有者通过版本四贡献协议接收显式版本四来源和结果。同一协议承载该来源的文件报告、状态及终止。旧协议许可拒绝该来源。来源与所有者记录保留原精确选择；恢复只终结旧采集许可，不把它授予新的运行中 Agent。

所有上下文后端在原来源区间内，为每个精确命令选择最新结果。失败、不可用证据及输出省略均会取代旧成功。语义汇总独立于生成文字保留类型化结果证据。命令会中断文件重建，因为其效果未经只读认证。[后端 README](../../../../packages/collaboration/development-task-context/README.zh.md) 负责当前投影行为。

## 考虑的替代方案

**解析终端文字或后处理后的工具值。** 打印文字与替代值可以声称不同的退出状态。实际 provider 观察保留进程事实的来源。

**仅在命令通过时发布。** 失败或中断后，旧成功仍会可见。

**把获准命令视为无副作用的测试。** 精确命令仍可使用既有执行权限修改文件或访问其他路径。分享许可不认证命令行为，也不允许跨越其副作用重放文件。

## 影响

既有人类所有的 Session 可分享检查结果，同时保留原 Task 和执行权威。隐藏 scope 更新上下文，无需手工转发或 recall。这不能证明任意命令验证了共享目标；报告的结果及输出仍由接收者解释。

当前许可涵盖原生前台 Bash。后台任务、外部进程、Claude 命令采集及任意工具结果需要单独集成。真实模型协作质量与物理双设备可用性仍是独立验收要求。
