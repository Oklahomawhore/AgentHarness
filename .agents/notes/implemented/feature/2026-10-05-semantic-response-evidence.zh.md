# Agent Note: 有限协作响应的语义证据

Status: implemented

[English](2026-10-05-semantic-response-evidence.md) | 中文

## 问题

面向接收方的摘要可以正确省略一条无关报告，同时 Task 修订号和来源账本发生变化。比较完整投影会把这类记录变化当成再次消耗本地自动响应许可的理由，削弱自动上下文选择对不同职责用户的价值。

## 决策

[语义后端](../../../../packages/collaboration/development-task-context/README.zh.md)通过现有激活接口提供保守的接收方证据。其摘要保留逐字选定摘要文本、引文、相关来源的完整正文与归属、必需记录、冻结父修订、接收方路由，以及 Task 身份、目标、范围和起源。只有属于当前 Task 的引用会在比较中去掉所捕获的修订号。精确投影仍保留该修订号及每个来源的处理结果。

结果版本 3–7 从证据摘要中排除按无关、自身发布或已替代省略的引用。完整交付覆盖保留每项处理结果。替换无关报告不能仅因早先报告变为已替代而再消耗一次自动响应。当前相关正文、来源身份、授权区间、序号、必需命令结果、撤回及结构化证据仍参与比较。相关来源变为无关时，其引用更新被移除，因此证据发生变化。不同摘要不会仅因可能表达相同含义而判为相等；相同引文不能掩盖相关正文的其他变化。

[原生接收组件](../../../../packages/collaboration/scope-agent-context/README.zh.md)负责调度。它仅在重新核查授权后，将证据与同一本地目标和绑定下实际成功完成的自动轮次所用证据比较一致时抑制响应。预取、普通用户请求、失败请求和取消的工作不能建立此基线。抑制响应不节省摘要预留次数，也不授予新的工具权限。

语义结果版本 5 保持这种比较，同时通过消息内的来源表与授权表消除重复的交付引用。即使摘要很短，必需同伴命令证据仍可能重复已有引文的来源和授权。渲染器只复用完全相同的既有身份，并显式列出编码后的必需条目，避免将原始不透明记录误读为引用。展开这些表可保留完整来源、授权、操作结果、publication 文本、引文和覆盖信息；表格编号不能影响激活。未知或不匹配的记录保留原始表示。该表示减少重复字节，不丢弃审计信息，也不缩短所选摘要。

结果版本 6 按精确 Task 修订号计数显示已替代的 publication 覆盖。否则，反复替换可能在仅保留一条当前命令结果时耗尽接收方预算。计数只替换模型可见的历史身份；完整处理结果仍保留在投影元数据、捕获的摘要输入和审计中。当前来源及所有其他省略原因保留各自引用。计数不授予权限，不影响激活，也不能从显示文本重建逐条历史身份。完整捕获证据及其他省略原因仍可能增长并超出配置限额。

结果版本 7 也按精确 Task 修订号计数已撤回的 publication 身份。终结来源区间会将早先的已替代记录改为已撤回，因此逐条保留撤回引用可能在持续工作后阻止终结通知的交付。通知仍是完整的必需证据，全部身份仍保留在投影元数据及捕获证据中。只有历史显示引用改为计数，其他省略原因和全部当前证据保持精确。没有摘要来源的撤回不需要调用摘要模型。这不改变请求版本 2：若另一活跃来源需要摘要，已撤回身份仍占用该模型输入。

请求版本 2 将完整捕获证据与实际模型消息分开。即使当前证据和接收方交付很小，付费摘要请求中反复出现的已替代身份也可能耗尽输入预算。因此，模型覆盖信息只将已替代的 publication 按精确 Task 修订号计数。同一条原子预留记录保留规范化完整捕获和精确发送文本；键同时绑定两者及请求版本。这让产生相同计数的不同历史仍保留各自审计和投影元数据。每条恢复或新预留请求均在改变预留状态前检查两种表示的对应关系，包括未完成及失败请求。版本 1 保留原有键和完整模型文本。独立部署限额约束新捕获和实际模型输入；无摘要来源的投影仅使用捕获与交付限额，不准备或预留模型调用。

审计恢复按记录版本重建每项结果，拒绝被改变的证据摘要或投影。版本 1–6 保留各自精确表示；版本 2 在保守比较中保留已替代省略，版本 1 保留精确激活。新计算使用不同的后端身份，同一审计 Session 仍保留累计预留次数；已提交日志不会被重写。

## 考虑过的替代方案

**比较完整投影。** 这仍适合 Text 后端，但会因仅限省略来源记账的变化唤醒语义接收方。

**只比较摘要文本或精确摘录。** 这会丢失未引用的来源变化、授权、必需撤回，以及可能影响接收方的冻结历史区别。

**丢弃历史出处。** 这会阻止完整的来源覆盖验证和审计恢复。显示计数保留历史处理结果，避免逐条重复身份；投影元数据和捕获的输入仍保留每个来源。

**让模型声明无需响应。** 未经检查的声明会向调度决策增加另一项模型判断。确定性证据摘要直接比较已记录证据。

## 影响

该机制支持保留各自人类目标和权限的 Agent。它不拆解共享目标，也不把一位参与者的权限委派给另一位。即使自动工作被抑制，在线上下文读取和审计记录仍会继续；下一次获准的模型请求会接收当前上下文。

相关性仍是模型判断。被误判为无关的有用普通报告仍可能被省略且不触发工作。必需命令结果、终态通知和结构化证据不依赖该判断。无密钥受控响应可以验证比较、调度和回放，却不能确立真实模型相关性、任务质量、总成本收益或双设备易用性。
