# Agent Note: 在同一原 Session 中组合获准工作来源

Status: implemented

[English](2026-10-14-combined-native-work-sources.md) | 中文

## Problem

一个人的既有 Agent 通常会在同一轮中修改文件、运行检查并解释结果。分开的文件与完整答复采集会遗漏部分证据，或仅为满足分享系统而要求辅助 Session。[人类拥有的协作](../process/2026-10-05-collaboration-follows-human-responsibility.zh.md)连接既有职责，不另外指派 Agent 代表同一个人。

## Decision

[原生采集器](../../../../packages/collaboration/scope-agent-contribution/README.zh.md)接受独立的第 6 版 native-work 来源。在一次申请中显式选择文件操作、精确前台命令和完整最终答复。至少选择一类，批准固定全部选择。既有许可保留原意，不自动获得组合授权。本地与远端管理均在保留授权前拒绝未知的 `sourceKind`；省略该字段仍选择已定义的工具观察来源。最终答复可能引用私有用户输入，因此其披露仍是表单中的独立选项。

每个 Session 的本地与远端角色各由一个 capture 管理授权、单调序号、累计样本额度、保留 lease 和耐久 outbox。文件、命令与答复样本保留各自的既有证据类型及原提供者或轮次来源。每个样本须匹配所选类别。停止、到期或撤销结束该采集的全部类别，独立读取许可继续保留。持久化失败保留有界可重试工作，冷恢复终止披露。保留样本与尚未完成的预留合计占满额度时，容量拒绝状态继续可见，包括早先完成记录刚保存成功的情况。

该来源使用第 6 版线协议及明确的耐久行后继格式。早期协议与行格式拒绝此授权，已提交的 Session 代际保持不变。精确载荷摘要固定全部许可字段；报告表示共享完整授权而不改变结果含义，语义捕获及激活也固定新来源选择。既有输入域保留其后端表示。[报告分配](2026-10-14-source-fair-reported-context.zh.md)继续限制完整字段、保留来源表示并报告省略。工具结果不证明答复正确，新答复本身也不取代早先答复。

不包含历史初始化、活动采集期间切换类别及并发连接多个远端所有者。[完整答复来源规则](2026-10-14-completed-answer-contributions.zh.md)排除失败、取消、steering 及受管理的自动轮次。有限自动接收需要独立的本地目标与额度。组合披露不授予执行权限，自动接收场景也不证明双向自动答复循环。Claude 适配器由于缺少所需原生完成证据，会拒绝这些原生入口、激活及恢复记录；[原 Claude 会话工作](2026-10-14-original-claude-work-contributions.zh.md)使用独立的权限与报告类型。

## Alternatives considered

**每个 Session 使用多份采集。** 运行时归属、队列、outbox 行、读取采用及自身报告省略按每个角色的一份采集识别。多份采集扩大生命周期状态，也要求用户为同一工作管理多份许可。

**分别用辅助 Session 执行工具和解释。** 这仅为通信系统改变人的 Agent 安排，不能证明原有 Session 之间的协作。

**从文件推断答复，或将其纳入文件同意。** 工具观察不包含人的完整解释，答复还可能披露获准文件操作以外的私有材料。

**依赖生成的请求 codec。** 严格分发会校验来源类别，但开发环境的 SRC 分发无需这些 codec 也能调用同一管理方法。未知类别不能建立明确的同意选择，因此由采集器拒绝。

## Consequences

一次经过核对的选择可以传输原 Session 的普通文件工作、前台检查与完整答复，无需逐次 publish 或 recall。来源与接收方保留独立分配的本地 Task、工具及历史。同一命令的新结果保留当前失败、替代早先成功，独立答复仍分别可追溯。共同样本限额可能更快耗尽，完整上下文也仍可能超过接收方额度。省略来源不能被当成完整覆盖或当前事实。

验证覆盖实际 Loader 工具和轮次事件、批准与未选类别、授权前工作排除、过期代际、共享容量、保存失败、撤回及冷恢复。TypeScript/Python SDK 与浏览器场景在固定 8,000 字节额度下对照耐久来源结果、所有者回执与实际接收请求，并以新 writer 记录保留历史判据。独立的空闲场景检查另行授权的自动请求及累计消耗，普通接收提示不算自动执行证据。

[冷恢复测试](../../../../packages/collaboration/scope-agent-contribution/tests/restore.spec.ts)拒绝不匹配的 Session 行键、已变化的 peer 身份及缩小后的保留容量，并保持来源持久化文件不变；库存限额对本地与远端域中的同一 Session 只计数一次。

原生验证属于中间能力。外部 CLI 验收需要已经运行的原 Session、明确的安装与网络步骤、精确授权、实际输入和时序；新建 Harness Session 不能替代。受控提供者不能证明真实模型理解、事实一致、所选来源以外的隐私或跨物理设备时延。真实模型与物理设备验收仍是独立要求。已实现的工具来源、完整答复和分配决策继续有效，其来源与表示规则仍适用。
