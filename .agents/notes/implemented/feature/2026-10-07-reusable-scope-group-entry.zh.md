# Agent Note: Shared scope entries retain independent member authority

Status: implemented

[English](2026-10-07-reusable-scope-group-entry.md) | 中文

## 问题

多个人可以共享目标，同时保留自己的 Agent、Task 和权限。单个采集的申请身份不能同时标识可复用入口：另一位申请者要么被拒绝，要么覆盖第一人的同意与授权。将共享入口视为一项授权，还会让某个人的离开影响无关参与者。

## 决策

[Scope access](../../../../packages/collaboration/scope-access/README.zh.md) 区分可复用的多人入口与每位认证申请者。每份申请保留精确的 peer、采集代际、来源选择、同意限额和所有者独立分配的身份。所有者批准和拒绝时，同时选择该身份、原入口和 proposal。重试返回保留的决定；在延迟提交之前取消申请，会保留该申请自己的终结意图。在同一个 Task 内，一个认证采集代际只能由一个申请入口占用。未批准的申请不能终止独立签发的贡献。明确批准只有保留精确授权之后，才可采用该贡献。

入口提供一个所有者持有的 Root Task。所有者逐人批准贡献和读取，成员另行同意本地采集与自动响应。[联合接收](2026-10-07-retain-local-task-during-joint-receiving.zh.md)保留每位参与者现有的 Task、历史和本地权限。共享目标不创建下级 Agent，也不允许所有者选择另一人的执行目标或额度。

一个持久 group 记录保存入口及保留成员，使准入与容量一起提交。独立的版本化存储 domain 保留单采集记录的解析器。多人申请请求使用自己的协议版本；旧入口保持单采集解释。两个 domain 保持相同的传输密钥归属，并共同参与总申请数、计划读取授权和恢复检查。完整记录字节限制为终结转换预留空间。终态申请者继续占用入口的累计容量和 Host 的总申请容量。

关闭入口不可逆，只阻止新申请。已有待审批申请仍可在原期限前批准；已批准授权保持各自的到期时间和撤销控件。取消申请或所有者拒绝只终止该成员计划中的贡献和读取。本地联合退出则结束贡献与接收订阅，不撤销所有者签发的读取授权。恢复地址不会改变成员关系或期限。探测只是即时观察，不能预留容量或授权采集。

原生加入流程在明确的本地读取与采集同意下接受多人入口。Claude 贡献适配器拒绝该入口类型，因为它不提供原生联合接收。所有者控件以独立游标列出入口和个人申请，显示公开采集身份以区分同一 peer 的不同 Session，并区分关闭新申请与撤销成员。成员的贡献结束后，只要读取权限仍有效，就仍可结束其协作。聊天视图隐藏后台信息交换；记录的请求上下文仍可重建。

## 考虑过的替代方案

**把单采集入口复用为多人入口。** 现有入口持有权和持久决定指向一个采集。扩大其语义会改变含义，并可能把某个人的授权或取消操作归给另一人。

**将容量与申请存为独立行。** 容量占用和成员记录需要跨行事务或可恢复的预留协议。有界的完整入口记录让两者一起提交，代价是入口大小有限。

**申请者离开后释放容量。** 保留终结意图可以防止延迟请求复活申请。保留这些意图的同时回收名额，会使保留数据超出声明的限制。

**关闭入口时关闭所有授权。** 所有者需要停止发放新访问权，同时避免中断已准入参与者。移除现有权限仍由逐成员撤销完成。

## 影响

参与者可以用同一入口连接各自拥有的 Agent，普通的已授权文件工作向共享范围提供事实。三方 SDK 与浏览器场景覆盖跨人更新、修正、可选有限响应、被动接收和独立离开。协议检查覆盖竞争申请、精确选择、重启和保留限额。受控响应证明请求投递和重建，不证明真实模型的协作质量。

所有者仍承载共享 Task 的权限；这不是无所有者的 peer 联邦。网络必须直连可达。加入不回填已有私有历史或文件；远端投影可能包含接收方自己的报告，因为 peer 采集不使用本地自身发布过滤所依据的 participant 身份。[用户指南](../../../../docs/user/guide/collaboration-network.zh.md)定义支持的加入路径与网络限制。
