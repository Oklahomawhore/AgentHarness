# Agent Note: 自动后续请求失去授权时停止

Status: implemented

[English](2026-10-06-stop-automatic-continuations-without-authority.md) | 中文

## 问题

自动 pulse 启动一个轮次，但不会出现在该轮次后续的工具续步中。只检查新认领的 pulse，会允许失败的 scope 读取在移除上下文后继续请求模型。清除轮次的自动身份还会移除其步数限制。监视器也可能在工具或读取进行期间独立暂停执行，即使下一次读取能够成功。

## 决定

[原生 scope 消费者](../../../../packages/collaboration/scope-agent-context/README.zh.md)在每次 pre-step 中保留当前自动轮次的归属。撤回上下文时，没有新认领外部输入的续步会被拒绝。准入在读取前及异步读取后检查执行许可；恢复连接不能恢复已暂停的轮次。新的外部输入可作为普通工作继续，并获得适用的当前上下文或撤回提示。

同一准入规则覆盖远端与 owner 本地上下文。Session 事件格式、grant、预算和核心 loop 行为均不改变。预留仍计入已用额度，已完成的工具副作用不回滚。

## 考虑过的替代方案

**仅拒绝带有 pulse 的输入。** pulse 标识最初的激活，不标识其工具引发的全部模型请求。后续请求需要保留的轮次身份。

**读取成功就继续已暂停的工作。** 读取权限和当前事实不能恢复本地执行许可。恢复执行须经过已有的显式 resume 操作。

**连同自动续步一起拒绝新的人类输入。** 新的外部 claim 有独立的请求意图。无需恢复自动额度，也可以继续普通工作。

## 影响

协作中断后不会再产生额外的自动模型请求，同时保留已完成的工作与审计历史。回归覆盖不可用、已结束、抛错、超限和恢复后的读取，并单独验证新的人类输入得到保留。这些检查通过受控模型回复验证准入行为，不证明模型质量、跨设备可达性或外部 Agent 私有会话的恢复。
