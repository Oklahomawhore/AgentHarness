# Agent Note: 在上下文额度内保留同伴报告

Status: implemented

[English](2026-10-14-lossless-peer-report-text.md) | 中文

## Problem

同一固定上下文额度中加入另一条命令结果后，重复归属信息和 JSON 字符串转义可能挤掉完整的文件更正。命令优先级不能判定哪项独立操作对接收者重要。即使剩余报告各自准确，丢弃更正仍可能改变接收者的下一步动作。

## Decision

[报告后端](../../../../packages/collaboration/development-task-context/README.zh.md#behavior)为规范的同伴报告原文使用可选的无损观察表。完整结果与原有警示文字继续保留；只复用已证明与完整 peer grant 相等的归属信息。展开无需调用其他工具或服务，即可还原包括 JSON 成员顺序在内的原文。不规范或未知的 publication 保持字面内容。完整转义输出必须同时小于原始表示与仅 grant 引用的表示。

这一表示保持来源分配、原子的文件组、命令对重建的阻断、精确省略证据和撤回规则不变。后端身份将新计算与已记录投影区分开。既有 Session 世代和已记录投影保持不可变。

## Alternatives considered

**推断命令重要性。** 文件名、命令文本和退出状态不能确立语义相关性，也不能证明命令验证了某个文件。

**扩大上下文额度。** 更多容量只会推迟同一问题，并违反明确配置的请求限制。

**默认使用摘要。** 模型摘要需要单独的路由、费用授权和质量证据。确定性编码可以消除重复字段，无需声称具备语义理解。

## Consequences

减少重复字节能让更多完整证据进入预算，但任何有限额度仍可能省略当前报告。已有自动响应覆盖检查仍会在当前预算省略时暂停；普通后续回合成功不能证明持续的空闲自动协作。编码不采集额外来源，也不授予执行权限。

独立的 JavaScript 与 Python 展开、实际持久化 SDK 请求和固定预算下的命令密度回归验证还原与交付。受控响应器只确立确定性行为。真实模型理解和第二台设备运行仍是独立验收缺口。另行授权的[完整答复来源](../feature/2026-10-14-completed-answer-contributions.zh.md)负责非代码成果自动采集。
