# Agent Note: Independent context delivery retains pending work and complete reports

Status: implemented

[English](2026-10-04-independent-context-delivery.md) | 中文

## 问题

已激活的独立贡献不再有待处理批准申请。因此，只处理申请的 worker 会在后续工具观察需要恢复之前停止。拥有者不可用时，原始样本或撤回虽然耐久保留，却可能需要另一次来源 Hook、页面读取或来源重启才能重试。

规范 peer 工具 publication 同时在带归属说明的文本和结构化字段中保存完整观察。文本后端将两份内容都序列化进模型投影。即使单份表示能放入接收者字节预算，这种重复也可能导致完整报告被排除。

## 决定

[Claude 适配器](../../../../packages/collaboration/claude-scope/README.zh.md) 为每个会话使用一个贡献 worker，处理待批准申请、未确认的原始样本和撤回。配置的贡献轮询间隔约束重复尝试。没有待处理操作时，worker 停止。新增采集与管理操作会调度保留的工作，包括 worker 退出期间新增的工作。

后台恢复在本地变更队列内取得最早待确认样本或撤回的快照，在队列外发送 peer 请求，再在队列内采用响应。采用时重新核对当前采集标识、代际、完整邀请和保留样本，保留更新的本地序列和回执状态。结束优先于发布；只有匹配的拥有者终止回执才能清理 outbox。取消使旧 workers 失效，销毁等待其完成。前景采集和启动恢复保留既有串行行为。

[文本后端](../../../../packages/collaboration/development-task-context/README.zh.md) 保留完整 publication 文本与来源信息。只有文本以换行和逐字节相同的序列化观察结尾时，投影才省略结构化 peer 工具观察。其他文本不变，不匹配的表示保留两个字段。耐久 publication、权限检查、来源选择、失败字段和整条 publication 的预算准入保持不变。后端 revision 6 使缓存的 revision 5 投影失效。

## 考虑过的替代方案

**从页面或下一次工具调用重试。** 两者都要求无关的用户动作，才能让已授权的工作到达拥有者。Host worker 在来源会话空闲时仍维持自动交付。

**后台 peer 请求期间持有全局队列。** 不可用的拥有者会阻塞其他会话。快照和采用需要串行，peer 往返不需要。

**扩大上下文预算或截断原始报告。** 扩大预算仍保留重复信息；截断会丢失工具证据。省略已证明重复的内容，能在现有预算内保留完整报告。

## 影响

恢复要求来源 Host 运行，并能访问保留的拥有者地址。地址变化仍需显式恢复路由。回执恢复与紧凑文本都不能证明外部模型采用或语义质量。后台重试不消除前景网络等待，也不授权任意文件读取。

聚焦测试覆盖样本与撤回的自动恢复、取消和其他会话进展、保留字节一致性，以及完整文本预算准入。已构建双 Host 场景执行安装生成的 Hooks、拥有者重启、耐久回执和读取投影。编写的 SDK 场景检查实际模型请求组装及脱离运行时的 Session 回放，不调用在线模型。
