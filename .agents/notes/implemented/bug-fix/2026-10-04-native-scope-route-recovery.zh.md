# Agent Note：原生路由恢复保留已有参与状态

Status: implemented

[English](2026-10-04-native-scope-route-recovery.md) | 中文

## 问题

Task 所有者可能保留设备密钥和已存授权，同时改变监听地址。原生参与者在贡献申请和读取订阅中保留旧路由。重复准入可能重置本地执行权限，而要求 Agent 存活或申请尚未过期会阻止旧贡献的清理。

## 决策

[原生贡献方](../../../../packages/collaboration/scope-agent-contribution/README.zh.md) 接受针对原采集或剩余接收续项的显式路由更新。完整申请入口除所有者地址外保持固定。观察到的路由版本和地址选择本次命令；保留的最后命令记录区分丢回复后的精确重试与后续变化。回到早先地址不会让旧命令重新有效。恢复保留目录、工具、限制、样本身份和取消意图。已冷却或过期的操作可完成撤回，不创建新 Agent，也不授予采集权限。后发的 Stop 或离开会使排队中的旧路由变更失效，阻止它替换停止信号。

[原生接收方](../../../../packages/collaboration/scope-agent-context/README.zh.md) 先记录只更新路由的 Session 事件，再更新已有订阅。事件保留绑定、授权、接纳身份、自动策略和累计额度。读取与等待在使用路由前落实该持久意图。单调订阅版本拒绝迟到的旧路由，包括地址循环变化的情况。终态订阅保持终态。读取状态比较防止迟到的联合恢复覆盖后续本地管理决定。如果贡献已使用新地址，用户可根据最新读取状态再次确认同一入口，而不恢复已暂停的工作。

[Scope access](../../../../packages/collaboration/scope-access/README.zh.md) 分别比较不可变授权字段和目标地址。恢复只接受固定到原所有者 PeerId 的直连 IP/TCP 地址；传输仍在连接时认证对端。地址语法不证明可达。联合恢复携带固定的读取状态比较值，贡献与读取保留独立结果。结束贡献不能隐式离开已接纳的读取订阅。

## 考虑过的替代方案

**重复准入。** 创建另一授权或绑定会丢失结清不确定请求所需的身份，并可能重置本地自动权限。恢复只改变原操作的路由。

**只比较地址。** 所有者可以从一个地址移到另一个地址后再返回。迟到命令因而可能匹配已过时的地址。单调路由版本独立于地址文本保留顺序。

**先更新存储，再写 Session。** 接收方可能在缺少持久 Session 记录时联系新路由。Session 意图先提交，原订阅更新可重试。

## 后果

所有者地址变化后，用户显式选择新路由。已采集工作和待确认撤回可在同一授权下继续。保存路由不代表送达、模型采用或权限续期。丢失所有者原身份或授权存储需要独立恢复；此操作无法重建它们。

验证覆盖丢回复、路由顺序、后续本地选择、终态清理、持久 Session 重放和实际请求内容。受控模型适配器验证传输与上下文行为，不证明真实模型质量或双设备易用性。
