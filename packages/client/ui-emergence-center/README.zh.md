# 涌现协作中心 UI

[English](README.md) | 中文

## 概述

`@deepseek-ai/dsh-client-ui-emergence-center` 在不可变 Root、Fork、Merge Task 谱系之上呈现可搜索的共享上下文工作区。左栏负责身份、搜索和 Task 选择，中间渲染只读 DAG，右栏先显示 Agent Session 连接，再显示显式共享上下文。Task 工作流不包含生命周期、证据、完成或审计控件；工作观察授权具有独立的 owner 控件。

## 行为

独立设备控件展示本机公开身份，提供绑定接收方身份的独立 Task 只读邀请及撤权。接收人粘贴邀请并选择一个已观察到的 Claude 会话，无须创建本地 Task 或授权目录读取。面板报告最近准备的上下文，或不可达、过期、撤权状态，不报告模型已理解。直连地址必须可达；默认回环监听仅支持本机。

邀请和审批控件仅提供 Host 身份当前公布的地址。存在多个地址时必须明确选择；已移除的地址不能继续作为选中值。回环选项会标明仅限运行 AgentHarness 的设备。要更改监听，请在该设备的本机页面打开[设置 → 插件 → 协作网络](../../bundle/web-app/README.zh.md#scope-collaboration-network)，保存后手动重启 Host，再刷新这里的地址。保存不证明对方网络可达，也不改变任何 Task 权限。

当前原生 Session 的标题栏提供“协作”入口。他人分享目标的主粘贴区接受只读邀请、单会话联合入口、多人入口或工具观察贡献入口。只读邀请进入明确连接流程，默认选择正常工作时接收。申请入口展开既有分享面板，由用户先验证连接，再填写权限表单；粘贴或识别内容本身不授予权限。自动协作必须显式填写本地目标、新增启动额度、每轮步数上限与最短间隔；邀请中的职责绝不会自动填写或批准该目标。表单将新增额度加到最近确认的累计预留次数上。取消的预留仍计数，该额度不限制 token、费用或 provider 重试。冷会话、子 Agent 和派生会话不能接受远端只读邀请；它绝不会为确认资格而创建 Agent 或发送提示词。

入口展示本地模式、暂停原因、预留用量，以及当前自动目标的活动记录。活动卡区分预留、实际请求、已完成轮次、证据未变而跳过，以及证据不完整导致的暂停，不展示共享正文。暂停会取消本功能当前的自动轮次并阻止新启动，保留手动工作与剩余预留额度。恢复可以使用同一许可的剩余额度，不增加总上限。离开结束本机接收，但不抹去历史或已发送的请求。过期、撤销、缺失或已离开的订阅不能直接恢复。“查看来源”切换到既有轨迹视图。本地 active 订阅只表示接收意图，不证明 owner 当前授权或模型已采用；[原生 scope 上下文](../../collaboration/scope-agent-context/README.zh.md)负责请求时校验与执行语义。

对于本机创建的目标，可按名称选择本机拥有的 Root Task，并明确连接当前运行中的 Session。连接使后续请求接收上下文，既不分享文件工作，也不自动开始空闲轮次。另一个初始为空的权限表单授权所选目录、write/edit 操作、期限与样本额度。提交携带已观察到的 Task 绑定及 epoch；绑定变化后必须重新同意。停止分享会撤回此本地来源，并保留读取连接。独立且默认关闭的自动工作表单，为精确 Task 绑定代际授权有限目标与额度。暂停保留该策略；关闭自动工作清除策略，但保留读取、文件许可和累计用量。“退出本地目标”通过单个受条件检查的 Host 操作停止自动工作、终结本地采集并清除所观察的 Task 绑定；结果未确认时必须重新读取状态。Task 绑定或自动执行绑定变化会清除未提交的自动同意。已断开的本地自动许可可单独清除，或由明确提交的远端邀请替换，不复用原自动许可。Task 仍在协作中心创建。

原生“协作”入口另行提供文件工作分享。Session 可保留本地 Task、自动目标和本地采集，同时申请向另一所有者贡献文件工作。每个目标分别显示许可、待处理操作和停止按钮；本地操作使用 `stopLocal`，对方贡献使用 `stop`。任一采集变化都不会替用户切换已选目标。此贡献许可不增加远端读取，也不改变已有自动目标。粘贴工具观察申请入口并验证连接。解析入口后，只读在线检查必须确认入口可用，才会显示权限表单；检查本身不创建申请或授权。不可达、已有申请、关闭、过期、拒绝以及容量受限的入口都不显示该表单。然后选择本地目录及 write/edit 操作，填写期限和样本额度，并明确同意所有者批准后自动启用。合格本地采集会一次性预填目录、工具和额度，不覆盖用户编辑；分享和自动工作同意初始关闭。修改入口、切换 Session 或建立申请会清除检查结果，迟到响应不能重新打开旧表单。检查成功不代表已批准或开始同步。表单展示采集、申请、待提交和撤回状态，不展示采集正文，也不声称模型已采用。“停止分享”携带所展示的精确采集身份，在 Agent 不再符合资格或未运行时仍可操作；状态确认失败后，必须重新读取状态才能继续修改。已经发送的操作在重连期间仍保持锁定。接收与自动启动权限都不授权外发。[原生来源贡献](../../collaboration/scope-agent-contribution/README.zh.md)负责采集与持久恢复。

同一文件工作表单提供独立、默认未选的选项，分享当前本地采集已保存的完成记录。它复用所显示的目录、工具，以及历史与后续实时操作共用的额度。同意固定采集身份、Task 代际、入口和权限字段；正常新增样本保留同意，身份或范围变化会清除同意。所有者的申请与已批准权限明确标出历史分享。来源分别展示等待选取、冻结后的选中与排除条数、截止时尚未完成的观察，以及实际所有者确认条数。这些数量不证明当前文件内容、完整历史覆盖或模型采用；初始化不会扫描文件。

尚未接收其他远端范围的原生 Session 可通过“邀请一个会话加入”同时申请读取和文件贡献，并可选在本机许可有限自动工作。所有者创建一个仅供一次采集使用的入口；来源分别确认整个 Root Task 的读取，以及所选目录、工具和额度，所有者再填写职责并明确批准两项权限。已有本地 Task、绑定代际和文件采集保持不变。读取同意固定精确本地目标、执行绑定及其读取管理序号；本地职责变化后须重新同意。职责用于上下文路由，不是读取 ACL。同一表单提供初始未勾选的自动工作选项，需明确填写目标、额外启动次数、步数上限和最短间隔。勾选后可预填原本地目标，但不会把旧自动许可转授给共享范围。批准后会在原 Session 中连接接收与已保存的自动许可，无需另一张表单、再次传递邀请或追加用户消息。省略时保持被动接收。所有者批准不授予执行策略。修改入口、Session、读取状态或已确认用量后，须重新确认自动许可。Agent 或接收服务更换会取消待采用的自动许可。读取同意保留所观察的读取管理序号，后续绑定变化要求重新确认。面板区分等待、连接中、已连接、已结束、被后续操作替换和失败。取消待处理申请也会取消尚未连接的读取。读取采用后，“停止分享”保留已连接的读取及其已授自动许可；可在上方单独暂停自动工作或离开读取。申请展示原始同意，读取面板报告当前模式和用量。“退出此次协作”结束远端采集，并仅结束此次加入建立的读取。原本地策略恢复为暂停，保留累计用量。共享范围面板管理当前组合策略，本地面板展示保留策略；退出本地 Task 前须先退出远端范围。尚未确认的读取清理在采集移除后仍可见，并阻止新申请；面板只根据已确认的接收状态报告完成。所有者分别查看贡献与读取权限，包括贡献结束而读取仍获授权的状态。

挂载的 Session 入口订阅调度与活动投影、运行状态及连接代际。即使调度状态未变，单独的活动变化也会刷新状态。投影变化使在途状态读取失效；单调递增的状态水位防止旧响应覆盖后来的观察。断线和 reset 清空已确认状态，并禁用变更，直到新的状态读取结束。每个变更携带表单所显示的绑定，在结果未知期间保持单个在途操作，并通过读取状态确认结果，不重复执行操作。接收权限草稿在错误与关闭弹层时都会保留；切换 Session 会隔离草稿及迟到回调。输入法未组词时，Escape 会关闭已打开的弹层并将焦点恢复到入口，即使状态变化移除了原焦点控件，也不会触发页面快捷键。界面不展示 Host 原始错误。

协作中心在启动时直接展开，可通过标题栏或侧栏按钮关闭。目录初始最多读取 200 个 Task。聚焦 Task 时最多请求四层祖先和两层后代，总上限为 500。父边不可修改，节点拖动只影响当前浏览器视图，Fork 或 Merge 会固定每个所选父 Task 的精确当前 revision。创建预览允许用户在提交子 Task 快照前排除单条父 Task 发布内容。发布内容显示参与者名称；独立 peer 报告及终结通知显示本地化来源标签与贡献者 PeerId。

没有本地 Task 时也能配置 Claude 项目并选择会话。使用 Claude Code 时，输入 Host 上的项目路径并配置或检查 hooks。在该项目中打开或重启 Claude，发送一条消息，再刷新已观察到的会话。选择一个会话；加入已选 Task 时，填写职责并确认允许观察的目录。加入远程 Task 后，其 owner 必须批准该会话的精确绑定，工作观察才会开始共享。目录预填会话工作目录，可自行修改。共享同一目录的会话保持独立；面板不会自动选中或批量加入它们。

普通 Task 加入表单允许采集所选目录内受支持的 Write/Edit 完成结果，包括明确标注的失败，不验证磁盘内容；不授予 Bash 采集或 API 文件读取权限。已观察到、已结束、已加入和已批准状态不代表在线或模型已采用上下文。Owner 面板列出已复制的远程绑定，并单独显示已批准或已终止的观察区间；这不表示每个绑定都请求了 Claude 采集。本地退出停止采集，尚未确认的远端撤销仍显示重试入口，已结束的会话也可重试。撤销待确认期间，该会话不能再次加入或更新授权。移除项目 hooks 会保留共享命令配置和既有授权；停止共享还需分别退出已加入会话的 Task。配置冲突时仍提供移除入口，但 Host 会拒绝删除已被修改、无法确认为自身所有的条目。[Claude scope](../../collaboration/claude-scope/README.zh.md) 负责配置和采集限制。Host 未提供该能力时，界面禁用相关控件并显示恢复指引。

独立来源粘贴所有者签发的申请入口，选择已观察会话、允许目录及期限、样本数和字节上限。默认来源采集该会话在授权目录内的 Write/Edit，无需逐文件登记；另一模式选择一个 OpenAPI 文件及操作。所有者核对精确的设备、来源类型、工具和额度。批准后，来源 Host 在后台自动启用，即使浏览器页面已关闭。工具观察报告参数与成功或失败状态，不代表已验证事实。本地采集、所有者贡献、读取和原生自动启动分别授权。[Claude scope](../../collaboration/claude-scope/README.zh.md) 负责采样与后台恢复；[scope access](../../collaboration/scope-access/README.zh.md) 负责申请与授权权威。次要的手工方式明确传递申请与返回的授权。

工具观察的联合入口或多人入口，为选中的 Claude 会话提供各自默认不勾选的读取和采集许可，不替换已有 Task 或读取连接。所有者一次批准后，Host 会在后台连接读取，无需另一份邀请，来源页面关闭时也可完成。连接会为支持的 Hook 准备上下文，不会启动 Claude，也不证明模型已接收。停止分享保留已采用的读取；退出此次协作会结束它的贡献和读取，并保留后来独立建立的读取。恢复地址会同时更新仍保留的连接，包括停止分享后的读取。

来源详情在重新加载或操作结果不确定后恢复原 capture。修改携带精确身份，并由 Client 目录持有，关闭面板不会解除操作锁。已提交的 Host 事件会使在途读取失效，并刷新已观察的来源和申请；通知不会重放，因此重新连接会查询新基线。确认失败会保留上次观察并禁用修改。停止操作保留取消意图直到所有者确认，包括已结束的会话。更新同一申请入口的地址会保留原许可与取消状态。核对后的邀请也只能更新原授权的地址；两种恢复都不会重新启用已取消的贡献。

所有者的申请和贡献清单独立于读取授权。“邀请多人加入同一目标”创建一个可复用入口，要求明确累计申请名额；拒绝、取消和到期的申请仍占用名额，Host 也会执行总容量限制。每位申请者分别同意并分别获批。“关闭新申请入口”阻止新申请，既有待批申请可在入口到期前继续批准，已有成员权限不变。“结束该成员协作”只撤销所选成员的读取与贡献。加载更多分别推进授权、单次入口、多人入口及各入口申请的独立游标；刷新从各自第一页开始。成员使用独立申请身份；可见的公开采集标识与代际和来源面板一致，可区分同一 peer 的多个会话。文件贡献结束后，只要读取仍获授权，仍可结束该成员协作。单次入口仍只接收一个 capture。每个入口保留原文本供恢复。UI 批准界面显示的精确来源额度，不会静默扩大。授权恢复在回复丢失后返回原许可，已结束授权仍保留终态。切换 Task 会隔离复制的入口和迟到回调。有类型的恢复提示不显示私有诊断；已批准申请或活跃授权均不代表送达或模型采用。

MCP 客户端卡片区分配置、进程在线、按 Session 的 Task 连接和上下文确认。目标 MCP Session 自行调用 `agentharness_task_connect` 并保存自己的 `bindingId`，即使多个 Session 共享一份客户端配置也如此。完成配置本身不会加入 Task。

页头是唯一的 Task 创建入口。Root 创建只要求已保存的显示名、Task 名称和初始共享上下文。Fork 和 Merge 增加不可变父 Task 选择，但没有计划、阶段、验收或评审前置。侧栏徽标统计当前身份创建的 Task，显示 `0` 至 `99` 或 `99+`，并预留足够宽度使数字保持在按钮内。

浏览器验收覆盖身份确认、唯一创建入口、Root/Fork/Merge 上下文继承、显式发布、按 Session 的 Agent 指引、徽标尺寸、可读的图节点尺寸，以及不存在生命周期控件。

原生恢复控件更新当前显示的原采集或读取绑定。贡献恢复预览同一申请入口的新所有者地址，即使 Session 已冷却或入口已过期，也保留文件权限与待确认撤回。联合恢复还携带显示时的读取状态比较值。独立读取地址表单保留原订阅、自动策略和累计用量。Host 持久化与刷新后的状态决定结果；保存地址不证明连接成功或模型已采用上下文。未授权自动工作时，按钮和接收面板在记录读取问题后仍显示“工作时更新”。历史读取原因不代表最近请求的结果或当前连通性。接收面板独立展示当前绑定已记录共享上下文的字节数、纳入的来源数与容量省略数；其他非零省略原因可展开查看。这些统计不含本地目标、聊天历史或工具定义，也不证明请求已发送、模型已理解或远端当前仍授权。离开或不存在匹配记录时，摘要消失。同一轮内步数变化会刷新摘要，不轮询也不启动工作。

<a id="model-experience"></a>

## 模型体验

本包通过操作间接影响模型；这些操作把模型可见上下文准入委托给 `dsh-development-task-context`、`dsh-agentharness-bridge`、`dsh-claude-scope` 或 `dsh-scope-agent-context`；显式原生自动许可可在 Agent 空闲时启动有界轮次，被动接收则不会。

#### KV Cache 影响

连接 Session 或发布 Task 上下文可能改变后续请求前缀，并降低该 Session 的缓存复用；浏览器渲染本身不会增加模型输入。

## 已知限制与延后工作

<a id="known-limitations-and-deferred-work"></a>

- 节点位置不会在浏览器间同步。UI 固定表单提交时可见的 revision，大型邻域使用有界占位符，而不是加载无上限图谱。

- 连接卡片会明确显示平台不受支持，且不提供自动或手动配置动作。

<a id="dev-note"></a>

### 开发备注

本包不发布运行时 invariant companion，因为 Task 与 scope 的权威状态由 Host 服务负责；本包只管理浏览器呈现与交互状态。
